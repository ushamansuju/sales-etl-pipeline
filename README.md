# Sales ETL Pipeline

## Overview
Built an automated ETL pipeline using Python, SQL, Apache Airflow, and Docker to ingest, transform, and load sales data for reporting and analytics.

- SQL
- Apache Airflow
- Docker
- Pandas

- Data cleaning and transformation
- SQL-based storage
- Airflow DAG scheduling
- Dockerized setup
